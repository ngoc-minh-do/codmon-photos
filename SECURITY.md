# Security Policy

## Supported Versions

This project is maintained as a personal utility. Only the latest release on
the GitHub Releases page receives security fixes; older releases are not
maintained.

## Reporting a Vulnerability

**Do not open a public issue for a vulnerability.** Use GitHub's private
vulnerability reporting instead:

1. Go to the repository on GitHub.
2. **Security** → **Report a vulnerability** → **Report a vulnerability**.
3. Describe the issue, the affected version, and, if possible, a minimal
   reproduction.

You can expect an acknowledgement within a few days and a status update as soon
as the report is triaged.

A valid report should include the affected version, steps to reproduce, and the
impact. Reports that arrive incomplete may be asked for clarification before
work begins.
